# Родительская страница: Инфо, Новая запись, Мои записи

## Для кого и зачем

Родитель должен быстро найти инструкцию, заполнить отдельную форму или открыть свои записи. Перестройка дизайна сохраняет текущие серверные правила и сценарии.

## Что должно быть

- Боковое меню с тремя пунктами: «Инфо», «Новая запись», «Мои записи». На телефоне шириной 375px навигация компактно размещается сверху, без горизонтальной прокрутки страницы.
- «Инфо»: назначение сервиса, исходные инструкции записи, выбор общей точки или метки у здания, поиск своих записей по телефону/PIN, изменение и отмена, правило закрытия за 24 часа по Астане, контакт организатора.
- По прямому запросу пользователя показать контакт Асхата: +7 747 888 2352, WhatsApp `https://wa.me/77478882352`, звонок `tel:+77478882352`. Только переход по нажатию, без отправки сообщений.
- «Новая запись»: существующая форма с прежними идентификаторами и обработчиками, картой выбора точки. Рядом с выбранным рейсом — рассчитанные дата и время закрытия по действующему правилу 24 часов.
- «Мои записи»: существующий поиск по телефону/PIN и список с возможностью изменить/отменить до дедлайна. Не обещать автоматический вход и хранение PIN.
- Переключение сохраняет DOM и введённые значения; в адресной строке отражается раздел, работают прямые ссылки и кнопки браузера «Назад/Вперёд».
- Действие «Изменить» открывает форму с выбранной записью. После успешного сохранения открываются «Мои записи», виден результат операции. Ошибка оставляет пользователя в форме с введёнными данными.
- Сохранять обе локализации, фон Бурабая и текущие ограничения карты. Активный пункт виден, фокус доступен, элементы управления не меньше 44px.

## Примеры

- Открыта главная страница без фрагмента URL → показана «Инфо».
- Родитель ввёл данные, открыл «Инфо» и вернулся в «Новую запись» → значения сохранились.
- Из списка выбрано «Изменить» → форма открылась с той же датой, временем и меткой.
- Сохранение успешно → показаны «Мои записи» и сообщение об успехе; ошибка → форма остаётся доступной.
- Выбрана поездка на 16:00 → показан её дедлайн за сутки, с полной датой и временем Астаны.

## Ограничения

- Это изменение существующего интерфейса, без публикации и изменения Supabase. Настраиваемый организатором дедлайн из 003 пока не реализован; отображать фактически действующее правило.
- Указанный пользователем контакт разрешён для публичного раздела «Инфо». Другие реальные данные не добавлять.
- Не устанавливать пакеты и не подключать новые ресурсы. При отключённом JavaScript разделы остаются на одной странице с якорями; работа записи, как и ранее, требует JavaScript.

## Готово, когда

- Есть три раздела и навигация между ними; форма/список не пересоздаются при переключении.
- Проверены оба языка, прямые ссылки, возврат назад, ввод данных, редактирование, сохранение, ошибка и отмена.
- Дедлайн рассчитан по выбранным дате/времени, контакт ведёт на указанные WhatsApp и телефон.
- При изменении ширины карта перерисовывается без потери сохранённой метки.
- На 375px нет горизонтальной прокрутки страницы, виден фокус, размер контролов от 44px.
