# Общие точки, время выезда и города

## Для кого и зачем
Организатор дополняет общие точки доставки и время рейсов; родители выбирают актуальные варианты на любом устройстве.

## Что должно быть
- Общий справочник Supabase: адрес и город общей точки, направление и время выезда. Добавление доступно только организатору после проверки роли сервером.
- Родитель получает актуальные варианты; общие точки фильтруются по городу назначения. Цена общей точки 5 500 ₸, своего адреса 6 500 ₸. Добавление времени действует ежедневно для выбранного направления; дедлайн прежний, за 24 часа.
- Два списка «Откуда»/«Куда»: Щучинск и Астана. Одинаковые города запрещены интерфейсом и сервером. Коды fri/sun сохраняются для совместимости.
- Существующие записи сохраняют адрес, цену и время. Старые общие точки остаются в справочнике. Новые варианты валидируются сервером, текст выводится через textContent.
- В шапке вместо B — предоставленный bil.webp с относительным путём.

## Примеры
- Организатор добавляет вымышленный адрес в Астане → он доступен родителю при выборе Астаны городом назначения после обновления справочника.
- Добавлено 18:30 для Щучинск → Астана → родители видят 18:30, сервер принимает запись до дедлайна.
- Одинаковые города → запись не отправляется; прямой запрос с одинаковыми городами отклоняется.

## Ограничения
- Изменять/удалять точки и времена, менять цены и настраивать дедлайн в этом шаге не требуется.
- Общий адрес вводит организатор; автоматической проверки здания нет. Координаты общего адреса пока не задаются; родительская метка сохраняется для своего адреса в Астане. Для своего адреса в Щучинске не предлагать карту Астаны.
- Обновление справочника при открытии страницы и по кнопке. Без связи не разрешать новую запись с неподтверждённым справочником.
- Подготовить миграцию 0005 после 0004, без автоматического применения к рабочей базе, без публикации.

## Готово, когда
- Без авторизации и с родительским ключом нельзя добавлять точки/время; организатор может. Дубли и неверное время отклоняются.
- Выбор городов, фильтрация точек, новое время, серверные ограничения, редактирование старых записей и сбои сети проверены на вымышленных данных.
- Логотип доступен локально, README содержит порядок миграции и проверки. Не выдавать локальные тесты за проверку рабочей базы.
