# Автоматические группы по координатам и гексам

## Для кого и зачем
Организатор формирует большие списки без ручного определения улицы каждой записи.

## Что должно быть
- После дедлайна кнопка формирует черновые группы одного рейса (дата, направление, время) на сервере из актуальных записей с координатами, ещё не входящих в группы.
- Стабильная локальная гексагональная сетка: сторона 300 м, центр проекции 51.16/71.43, шаги вычисляются в метрах. Номер ячейки определяется координатами, без внешних API и библиотек.
- Допускается объединение собственной и соседних с исходной точкой ячеек. Выбирать ближайшие точки детерминированно, максимум 7 детей; диаметр группы не больше 1500 м. Остатки — неполные группы. Не смешивать рейсы, не дублировать пассажиров.
- Названия и число улиц не определяются. Пользователь разрешил приблизительный охват с погрешностью ±2 улицы относительно прежнего ориентира 3–4. Геометрия не гарантирует этот допуск; не выдавать его за проверенное количество улиц.
- Координаты общих точек организатор задаёт один раз; автогруппировка использует их. Записи без пригодных координат показывать отдельно, не терять и не подставлять центр города.
- Существующие группы не удалять и не менять автоматически. Организатор назначает каждой новой группе водителя, затем явно публикует весь рейс. Без водителя, при нераспределённых или устаревших записях публикация запрещена.
- Изменение координат общей точки снимает публикацию; устаревшие координаты группы блокируют повторную публикацию до пересборки.

## Примеры
8 близких детей → группа 7 и группа 1. Два соседних здания по разные стороны границы могут попасть в одну группу. Один адрес без координат → отдельное сообщение и запрет окончательной публикации рейса, пока запись не распределена.

Для автоматической сборки эта спецификация имеет приоритет над прежним требованием точного предела четырёх улиц в specs/002, 003 и 007. Ручная сборка сохраняет прежние правила.

## Ограничения
Это приближение по прямому расстоянию, не проверка существования здания, не маршрутизация по дорогам и не учёт мостов/ограждений. Общую карту организатора не возвращать. Реальные данные не использовать в тестах. Миграцию 0008 подготовить после 0007, рабочую базу и сайт не менять автоматически.

## Готово, когда
Проверены границы гексов, соседние ячейки, вместимость, остатки, отдельные рейсы, отсутствие дублей, неизменность уже собранных групп, повторный запуск, невалидные/отсутствующие координаты, назначение водителя и проверка перед публикацией.
