# Карусель подсказок Инфо

## Для кого и зачем
Родитель читает четыре подсказки по очереди в горизонтальной карусели.

## Что должно быть
Автосмена каждые 6,5 секунды; при наведении и фокусе движение останавливается на текущей карточке. Стрелки и четыре переключателя. Кнопки паузы нет по уточнению пользователя. Горизонтальное пролистывание касанием, клавиши стрелок на области. Содержимое и ссылки сохраняются. Контакт организатора вне карусели.

## Примеры
Наведение на подсказку о PIN → она остаётся на месте. Уход курсора при отсутствии фокуса → автосмена возобновляется.

## Ограничения
Без библиотек, API и изменения базы. Отключать таймер на скрытой вкладке и вне раздела Инфо. При reduced-motion автосмена изначально выключена. Без JavaScript карточки доступны горизонтальной прокруткой. Сохранять обе локализации.

## Готово, когда
Проверены автосмена, пауза по наведению/фокусу, ручное переключение, скрытый раздел, режим уменьшения движения. Все четыре блока и контакт сохранены; проверки и непроверенное перечислены.
