Откройте выбранную родителем точку по ссылке в записи и поставьте отметку в списке. Проверка адресов пока ручная.

Вход организатора

Вход по учётной записи Supabase, которой администратор выдал доступ организатора. Телефон и PIN родителя здесь не подходят.

Управление развозкой

Готовые списки

Выберите дату и направление, проверьте записи, сформируйте группы и выгрузите список для Excel.

В списке все записи на выбранную дату, включая рейсы с открытой записью. Пока запись открыта, список может измениться.

Отметки сохраняются только в этом браузере. Очистка данных браузера удалит их. После обновления страницы нужно войти заново.

Отметки не сохранятся: локальное хранилище недоступно или повреждено.

Выгружается показанный список в XLSX. Изменения в файле не обновляют сайт. Храните файл со списком в месте с ограниченным доступом.

    Формирование и публикация групп

    Сначала обновите основной список на нужную дату. Выберите записи одного рейса после дедлайна. Проверьте здания и ближайшие улицы вручную; автоматического определения улиц нет. Не больше 7 детей и 4 улиц, расстояние между зданиями — до 1 500 м. Для общей точки укажите её координаты. Число улиц и расстояние не заменяют проверки соседства.

    Автоматически собрать по гексам

    После дедлайна система возьмёт актуальные координаты рейса и создаст группы до 7 детей. Учитываются своя и соседние ячейки, расстояние между адресами до 1 500 м. Гекс со стороной 300 м — приблизительная зона; число улиц и дорожные препятствия не проверяются. Существующие группы сохраняются, распределяются только ещё не включённые записи.

      Ручная сборка и исправление записей

        Публикация действует для всего рейса: все актуальные записи должны быть распределены. После изменений расформируйте устаревшие группы и соберите заново. Родитель увидит имя, телефон и Kaspi только после публикации.

          Адреса и время

          Общие точки и время выезда

          Новые варианты доступны всем родителям после обновления формы. Время добавляется для всех дат выбранного направления, по Астане. Дедлайн — за 24 часа до выезда.

          Добавить общую точку

          Укажите улицу, здание и при необходимости название места. Проверьте адрес перед добавлением. Цена общей точки — 5 500 ₸.

            Добавить время выезда

              Изменить адрес общей точки

              Обновится вариант для новых записей. В существующих записях сохранится прежний адрес; при необходимости измените их в «Готовых списках».

              Координаты общей точки для автогруппировки

              Выберите общую точку выше. Задайте координаты здания один раз — они будут использоваться для записей с этой точкой. Не вводите центр города вместо неизвестного здания.

              Дедлайн конкретного рейса

              По умолчанию — за 24 часа. Новый дедлайн действует только для указанного рейса и не может быть позже выезда.

              Водители

              Добавьте водителей и их реквизиты для оплаты. Назначение водителя группе и публикация доступны в «Готовых списках».
